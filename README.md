# Leandro Cherulli | Portfolio

My personal portfolio showcasing my background, skills, projects, and experience as a Computer Science student at Kennesaw State University pursuing a career in data analytics.

Built with HTML, CSS, and vanilla JavaScript. No dependencies or build step are required.

## Features

- Responsive layouts for desktop and mobile screens.
- Light and dark theme toggle.
- Dedicated pages for my background, skills and projects, resume, and contact information.
- Downloadable PDF resume.
- Email copy button and links to my LinkedIn and GitHub profiles.
- Keyboard skip links and accessible navigation labels.


## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Homepage and introduction |
| `aboutMePage.html` | Personal background |
| `skillsPage.html` | Skills and projects |
| `resumePage.html` | Experience, education, and resume download |
| `contactPage.html` | Contact information and social profiles |
| `Effects.css` | Shared styles, themes, and responsive layouts |
| `scripts.js` | Theme toggle and email copying |
| `images/` | Site images |
| `Leandro Cherulli - Resume.pdf` | Downloadable resume |

## Updating the site

Edit the HTML pages to update content, `Effects.css` to adjust styling, and `scripts.js` to change interactive behavior. Refresh your browser to see changes.

To update the resume, replace `Leandro Cherulli - Resume.pdf` with the latest version. If you rename it, update the download links in both `index.html` and `resumePage.html`.
